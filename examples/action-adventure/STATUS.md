# Action first room

## Scope
First executable experiment for the owner-authorized top-down action-adventure phase.
The existing visual-novel code is preserved, but receives no new feature work.

## Evidence states
- Nine original editable pixel sources committed.
- vesper-action has pure collision, movement and arc-attack tests.
- vesper-action-demo boots separately, with one drone and a terminal/exit condition.
- Real GPU, combat feel, visual quality, pixel readability and layout are **not**
  accepted until physical testing and screenshots are reviewed.
- The game uses **no copied Eastward art** and no recycled Vesper VN soundtrack.

## Anti-scope-creep gate
Do not add crafting, new rooms, procedural generation, loot or inventory until
the owner says movement and combat in this single room are worth expanding.

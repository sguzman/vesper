# VX07 — Atmosphere and micro-interaction feedback

VX07 adds optional, external theme-owned 2D atmosphere and feedback without changing the Vesper story language, save file format, engine binary for a specific game, or the external asset policy. The engine uses reusable Bevy sprites and UI entities; no authored images, fonts, sounds, or custom shaders are required. A 128×128 soft radial opacity mask is generated once during Startup (64 KiB) and cached for all glow sprites; no texture generation occurs during Update or rendering.

## Example external theme

```toml
[atmosphere]
preset = "moonlit"       # off | motes | glow | vignette | moonlit
seed = 481516            # stable u64 layout seed
count = 16               # 0..32; moonlit caps moving motes at 16
speed = 8.0              # 0..24 logical pixels/second
radius = 3.0             # 1..8 logical pixels
opacity = 0.15           # 0..0.35
color = [0.9, 0.84, 1.0, 1.0]

[feedback]
focus_seconds = 0.16     # 0..0.35 (0 = instant)
confirm_seconds = 0.14   # 0..0.35 (0 = off)
cue_opacity = 0.45       # 0..0.65
cue_color = [0.96, 0.75, 0.40, 1.0]
```

Both sections are optional. Their default atmosphere is **off** and default focus/confirmation duration is **zero**, preserving existing games. Unknown fields or invalid numeric/color bounds fail external theme validation before loading or applying hot reload.

## Runtime behavior and resource policy

- Motes are generated by a fixed integer hash from the author-provided seed and particle index. Their positions are bounded by the logical viewport. Their elapsed motion clock freezes while paused, in menus, in Settings, or when the story finishes. Reduced motion hides moving motes entirely.
- Glow uses three softly feathered radial fields sharing the same cached mask. Vignette uses twelve translucent edge bands, no custom shader. Moonlit combines up to 16 motes with three glows and twelve bands. The total entity count is hard-capped at **32**; Off spawns none. Missing game artwork or audio cannot break these procedural effects.
- Theme hot reload rebuilds these bounded entities **only if the authored atmosphere changes**. Normal frames only update bounded transformations, colors and dimensions. Nothing reads or writes files, builds image assets, or generates artwork in Bevy's update/render systems.
- Focus transitions use one shared easing system for menu rows and independent story-choice rows; existing keyboard and pointer activations use the same confirmation cue. The cue is a short, optional color stripe. It does not advance dialogue or alter narrative state. Reduced motion disables confirmation animation and uses instantaneous focus state.
- The effects are presentation-only and do not appear in serialized narrative saves. User-owned accessibility preferences take precedence over external theme motion.

## Evidence and acceptance

Unit tests check seed determinism, viewport bounds, preset entity caps, invalid theme rejection, focus palette endpoints, and reduced motion. `.github/scripts/atmosphere_smoke.py` uses copied external Clockwork Moon fixtures to capture actual render frames of moving motes, frozen pause, hot-reloaded Glow/Vignette/Moonlit/Off presets, reduced motion, focus transitions and confirmation cues. CI publishes `vesper-atmosphere-feedback` screenshots and logs.

VX07 only receives its seven roadmap points after full graphical CI and prior milestone regressions pass.
